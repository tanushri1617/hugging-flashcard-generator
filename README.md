# Hugging Face Flashcard Generator

A simple Python project that uses a Hugging Face AI model to generate study flashcards.

## Features

- Takes a topic from the user
- Generates 5 flashcards
- Provides Question and Answer for each flashcard
- Measures the AI response time
- Uses Hugging Face Inference API

## Technologies Used

- Python
- Hugging Face
- Hugging Face Inference API
- python-dotenv
